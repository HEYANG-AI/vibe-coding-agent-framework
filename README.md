# ✨ vibe-coding-agent-framework
一个基于 Python 的自动化 Agent 框架，专注于构建可扩展、可观测的智能任务处理系统。

---

## 🚀 快速开始（一键运行）
### 1. 克隆项目
git clone https://github.com/HEYANG-AI/vibe-coding-agent-framework.git
cd vibe-coding-agent-framework

### 2. 安装依赖
pip install -r requirements.txt

### 3. 启动项目
python -m vibe_agent

---

## 📦 功能特性
- 智能任务调度与执行
- 浏览器自动化操作
- 工作流可视化编排
- AI 自动异常修复
- 自然语言指令支持
